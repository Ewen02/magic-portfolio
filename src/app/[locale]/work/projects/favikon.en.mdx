## Overview

**Favikon** is a B2B SaaS platform for **AI-augmented influencer marketing**, used by marketing teams, agencies, and brands to discover, analyze, contact, and manage content creators at scale.

### By the numbers

- **210,000+** users
- **11.5M+** referenced creators
- **30M+** indexed posts

The platform combines:
- **Massive data**: creators, campaigns, performance across all social networks
- **Real-time**: messaging, analytics, dynamic widgets
- **Artificial intelligence**: LLMs, semantic search, autonomous agents
- **Automation**: outreach, contracts, reporting

I work as a **Full Stack Developer (Frontend Focus)** on a product with extensive functional scope, in collaboration with the product, design, and data teams.

## Frontend contributions (Next.js / React)

### Architecture & Patterns
- Implementation of a large-scale **modular feature-based architecture**
- Definition of standard patterns: `.api` → `.hook` → `.type` → `.socket`
- Strong focus on **performance** (lazy loading, virtualization, streaming)

### Advanced state management
- **React Query**: server cache, smart invalidation, optimistic updates
- **Redux Toolkit**: persistent global state for cross-feature data

### Real-time
- Implementation of **Socket.io** and **SSE** for live updates
- **Token-by-token streaming** for a "live typing"-style UX on AI responses
- Drag & drop widgets with real-time synchronization

### Complex features
- A **global cross-feature search** system
- Configurable **drag & drop widgets**
- **Messaging** interfaces with AI streaming

## Backend contributions (Node.js / Express)

### Critical business modules
- **Campaigns**: complete management of influencer campaigns
- **Discovery**: creator search and filtering
- **Messaging**: communication with influencers
- **Reports**: generation of analytics reports

### Architecture
- **Service / Controller / Repository** pattern
- Integration of databases suited to different use cases (SQL, NoSQL, vector DB, cache)

### Performance
- Multi-level caching
- Optimization of real-time connections (SSE, WebSockets)

## Mobile application (iOS / Swift)

- Development of a **native iOS application in Swift**
- Porting of the platform's key features to mobile
- Integration of the APIs and real-time flows on the iOS side

## AI & Agent systems

### Multi-agent (LangChain / LangGraph)
- Development of orchestrated **multi-agent systems**
- Specialized agents: channel selection, contextual analysis, conversational memory
- Intelligent orchestration of AI workflows

### AI streaming
- **SSE streaming** for real-time AI responses
- **Token-by-token** display on the frontend
- Handling of interruptions and context

### Semantic search
- **Qdrant** integration with embeddings
- Creator search by semantic similarity
- Continuous improvement of result relevance

### Automated generation
- Personalized messages for outreach
- Influencer contracts
- Intelligent creator recommendations

### AI observability
- Tracing of AI requests
- Performance and quality metrics
- Feedback system for continuous improvement
