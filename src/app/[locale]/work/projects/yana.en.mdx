## Overview

**YANA** (You Are Not Alone) is an **Epitech Innovative Project** developed over **2 years** by a team of **7 students**. The project won the prize for **best EIP at Epitech Rennes**.

The application is a **private, secure social network** designed for:
- People affected by **rare diseases**
- **Caregivers** and loved ones
- Patient **associations**
- **Healthcare professionals**

Access is granted **by invitation only** (doctors or associations), ensuring the confidentiality and relevance of the exchanges.

## Goals

- Provide a **secure and inclusive** space that fosters mutual support
- Build a complete product: **web + mobile + backend**
- Ensure a smooth experience, including in **offline mode**

## Mobile Application (Flutter)

### Contributions
- Design and development of the Android/iOS app
- Creation of the interfaces from the Figma mockups
- Implementation of **offline mode** for data accessibility
- API integration and state management

### Features
- News feed and posts
- Private messaging
- Topic-based groups
- User profiles

## Web Application (React / Next.js)

### Contributions
- **Complete rebuild** of the web version with React and Next.js
- Development of new features
- Integration of Tailwind CSS and SCSS
- Performance optimization

### Features
- Complete dashboard
- Group and community management
- Notification system
- Administration for associations

## Backend (NestJS)

### Contributions
- Centralized API to manage users, groups, and exchanges
- Management of security, roles, and confidentiality
- Integration with the web and mobile apps
- Deployment with Docker and GitHub Actions

## Tech stack

- **Mobile**: Flutter, Dart
- **Web**: React, Next.js, TypeScript, Tailwind CSS, SCSS
- **Backend**: NestJS, TypeScript
- **DevOps**: Docker, GitHub Actions
- **Design**: Figma
- **Methodology**: Agile (4-month sprints, weekly meetings)

## Challenges and lessons learned

- Designing a **secure** platform that respects the confidentiality of health data
- Working on a **complete architecture** (web, mobile, backend) within a distributed team
- Implementing a **reliable offline mode** on Flutter
- Ensuring **functional consistency** between the web and mobile versions
- Managing **project coordination** with sprints and follow-up checkpoints

## Impact

- **Winner at Epitech Rennes**: recognition of the project's quality and relevance
- A **functional and stable** product, suited to real-world use
- A rewarding experience in **interdisciplinary collaboration** and **agile project management**

## Final status

The YANA project is **finalized** following the end of the Epitech cycle. The application is:
- **Functional** and complete
- **Deployed** in a stable environment
- A **major reference** in my journey in full stack and mobile development

This project represents the culmination of two years of collaborative work on a topic with a **positive social impact**.
